AI Builders 日报 · 2026-09-22

September 22, 2026

9 月 22 日：Codex 团队预告周二「reset」，1.2 万赞全网蹲守开盘；OpenClaw 一天连上三条热帖，「Meta 在用 OpenClaw」的传闻被创始人亲口澄清；Grok 4.7 被拿来啃逆向工程的硬骨头，实测惊艳。

今天所有信号指向同一件事：Agent 正在从「工具」变成「入口」。OpenAI 蓄势待发的大更新、Meta 受 OpenClaw 启发的自研动作、Box CEO 口中「使用软件是人类 100 倍」的 agent——人机交互与商业流转的中间层，正在被 agent 接管。

一、OpenAI Codex：周二「Reset」预告

  • Thibault Sottiaux（OpenAI Codex & ChatGPT 团队）发布今日最热一条（12.5k 赞、1700+ 回复）：「Ladies and gentlemen... start... your... ENGINES.」他承诺周二兑现此前说的 Codex「reset」，还「among some other things」。社区普遍预期是 Codex 大版本更新或订阅体系调整，就等开盘。原文
  • Nikunj Kothari（FPV Ventures）的横评：Codex on Mac + Computer Use「简单无敌」，把手动工作流丢给它就能 one-shot 完成；面向大众的零配置 agent（Instinct、Muse）则在手机浏览器场景表现出色。他只提一个要求：OpenAI 把「agent」推向大众时，请把工作流展示出来、降低上手门槛。原文

二、OpenClaw 生态：传闻澄清、自主权与安全审计

  • Peter Steinberger（OpenClaw）澄清疯传的「Meta 在用 OpenClaw」：Meta 是受其启发自建了 agent，Nat 和他的团队做得很棒（4.4k 赞）。一条传闻的最终定论：是致敬，不是采用。原文
  • 他同日抛出两条高赞观点：自托管 claw 的美妙之处在于「他们封不掉你」（1.1k 赞，评论区激辩平台封锁与用户自主权）原文；面对外部安全审计，「功课做足了，没发现 critical 问题」（433 赞）——开源 agent 项目的安全答卷。原文

三、模型与编码工具实测

  • Guillermo Rauch（Vercel CEO）给 Grok 4.7 出了道狠题——逆向工程一个正在运行的二进制，结果「漂亮地解决了，而且非常快！」（2.2k 赞）xAI 的编码/逆向能力开始被一线开发者点名。原文
  • Garry Tan（YC CEO）：capydotai 能跟踪多步工作流，跑大 PR 比单独用 Codex 或 Claude Code 都快，是他最近最喜欢的 agentic coding 秘密武器（356 赞）原文。他还晒了在自家 GBrain 上执行「野心勃勃的修 bug 浪潮」的实例：任务清晰切分、自动并行、干净的 GitHub PR 与 CI 流程。原文
  • Rauch 另宣布：除了 type-safe 的 AI SDK，Vercel AI Gateway 现已支持通过 HTTP 直接调用 Jev。原文

四、Agent 时代的商业模式

  • Aaron Levie（Box CEO）抛出核心判断：AI agent 使用软件的频次将是人类的 100 倍。即便 UI 逐渐隐入背景，数据托管（CRM/ERP/结构化与非结构化平台）、安全护栏、业务逻辑编排这些核心原语反而更重要——做好「agent 的安全层与数据层」的平台正面对巨大机会，新创公司和动作够快的现有平台都有份。原文
  • 他还算了笔账：当 agent 能端到端搞定任意复杂任务，大量消费必然流经它们——你先丢给它琐碎日常，用顺手后复杂任务也来了，摩擦降低反而让人花得更多。agent 提供商和与之交互的服务层（商业、本地、B2B）双赢。原文
  • Peter Yang替广告业提问：如果生意的根基是向人类投放定向展示广告，当 agent 替人浏览网站、直接把事办完时——广告给谁看？（379 赞）原文
  • Amjad Masad（Replit CEO）转发并断言：AI 正在复兴 American Dream（566 赞）。原文

五、产品观与使用习惯

  • Thariq（Anthropic Claude Code 团队）：「use big pictures and few words」这句话我现在每天要打好几遍——1.8k 赞。和 agent 沟通的最佳实践正在被一线用户重新校准：少字多图。原文
  • Nikunj再补一刀：热衷 tokenmaxxing（狂堆 token）的公司，产品体验往往最差——好产品靠的是 curation & gardening（策展与园艺式修剪），不是把厨房水槽一股脑丢给 agent。「Less is more 从未如此贴切。」原文
  • Peter Yang的生活方式变化：「我已经不再活在 email 和短信里，我活在和我的 agent 的聊天里。」原文

博客精选

Claude in Chrome 正式 GA（Claude Blog）：面向所有付费计划开放。Claude 现在可以在浏览器中自主执行操作，无需逐步批准——每个动作先由安全分类器校验是否安全、是否符合你的请求。它补上了 API 覆盖不到的空白：内网面板、遗留系统、vendor portal，用你现有的登录态读页面、打字、点链接、翻页、填表。GA 的底气来自一年来对 prompt injection（藏在网页/邮件/表单里的恶意指令）防御的持续加固：模型与探针训练双双升级。
