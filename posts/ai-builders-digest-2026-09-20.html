周日的 feed 短而精：8 位 builder、11 条帖，没有爆炸性官宣，但几条长帖凑出了一个完整的光谱——agent 的机会、它的安全反面、以及「AI 改进 AI 自己」的远景。贯穿其中的主线是：在 agent 时代，「亲手动手」这件事正在被重新定价。

当 FPV 的合伙人每天雷打不动写两小时代码、Box CEO 宣布「新的注意力战争要向 agent 争夺」、Richard Socher 拿 6.5 亿美元做「AI 改进 AI」时，信号已经足够清楚：理解模型唯一靠谱的方式是亲手用它，而 agent 正在成为下一代的流量入口。

一、动手方法论：Nikunj 的「每天两小时」

FPV Ventures 合伙人 Nikunj Kothari 自述每天花约 2 小时编程、做 side project、折腾新 repo，几乎每天都会收到 DM 问「你是 VC，为什么要干这个」。他的回答是：这一轮东西动得实在太快，不动手就永远学不会接下来会发生什么（原文，246 赞）。他把「投资 AI 时代」拆成三层功课：一是读懂模型能力、判断下一代模型会在哪里变强——读 model research 论文仍有大量 alpha；二是看模型需要什么工具才能完成更长程的任务（infra 机会）；三是理解 harness 能力如何让模型去搭建「自主公司」（app 层机会）。他的建议很实在：先动手 10 天，你多半会同样上瘾。

二、Agent 经济学：竞争的对象不再是用户，而是 agent

Box CEO Aaron Levie 给出了今天最值得展开的论点：个人 agent 是 build something that agents want 的终极形态。以 Meta 的 Muse 这类产品为例：你要能把任务完整交给 agent 端到端完成，agent 就必须能顺畅地用你的工具或用自己的工具——走你的 MCP 或 CLI、浏览你的网站、完成交易。他断言：接下来要争夺的注意力不是用户的，而是 agent 的；最能支撑 agent 点外卖、下单电商、订机票、调用本地服务和数据的工具，就会被用得最多——「这会是 App Store 以来消费科技最大的一次机会与洗牌」（原文，340 赞 / 40 转）。

但落地是渐进的：Linear 前产品负责人 Nan Yu 同时试了 Muse 和 Instinct，两个都声称「还不能打电话」，他忍不住问是不是还在灰度推送（原文）。昨天还在替人砍价省 $800/年的能力，今天换个地区可能就没开通——个人 agent 的能力分布目前仍是滚动推送状态。

三、同一枚硬币的反面：agent 深度接入系统的安全账

SPC 普通合伙人、Dropbox 前 CTO Aditya Agarwal 泼了一盆冷水：看到 Gemini、OpenAI、Anthropic 争相宣布更激进的 agent 系统接入后，他「100% 确信」已经有一批大公司在毫不知情的状态下被国家级攻击者渗透（原文，46 赞）。这不是阴谋论式唱衰，而是对机会叙事的镜像：agent 拿到的权限越深、越接近核心系统，攻击面就越大。机会（第二节）和风险（本节）是同一条技术路线的两面，只谈前一半是危险的。
