四、经济与趋势

Aaron Levie（@levie）：对 Token 消费的 Jevons 悖论做了最直观的解释。企业有无限的任务想要自动化，但每个任务的 ROI 取决于自动化成本。随着 Token 变便宜（在能力达标的前提下），企业可以把自动化推到更多工作场景——处理每份合同、读取每条日志、监控数据流、让后台 Agent 执行工作流。Token 价格降 50% 可能带来 5 倍的消费增长。这就是为什么持续降低 AI 成本对所有市场参与者都是好事。

  • 要点：Token 降价的 Jevons 效应——成本下降不缩减市场而是放大消费。50% 降价 → 5 倍消费量是关键经验数据。

Scaling Managed Agents：将大脑与手解耦：Anthropic 推出 Managed Agents——一个托管服务，通过少量接口运行长周期 Agent。核心设计哲学借鉴操作系统：操作系统通过虚拟化硬件（进程、文件）为"尚未设想的程序"提供稳定抽象，Managed Agents 同理虚拟化了 Agent 三大组件——session（append-only 日志）、harness（调用 Claude 并路由工具的循环）、sandbox（执行环境）。每个组件可独立替换而不扰动其他。文章还提到 Claude Opus 4.5 已不再有 Sonnet 4.5 的 "context anxiety"（上下文焦虑——感知到 context 将满就提前结束任务），说明 harness 假设需要随模型迭代。
