AI Builders 日报 · 2026-11-02

November 02, 2026

今天这批 feed 有个非常一致的信号：AI 的核心战场正在从「谁能训出更大的模型」转向「谁能把智能变成自己的资产」——Karpathy 用 Claude 三小时搭出一个视频推荐站、Replit CEO 警告补贴型 AI 订阅会被「直接掀桌」、Vercel CEO 喊话「拥有你自己的智能」、Box CEO 说工作描述正在变成「管理一支 agent 团队」。

真正的护城河不再是模型本身，而是你能不能掌控自己的数据、连接与运行时——当补贴退场、模型同质化，只有「拥有自己智能」的人才不会被 rug pull。

一、头条：Karpathy 的周末 Hack——HackerTube

Andrej Karpathy 又交出一个「周末规模」的惊艳作品：HackerTube。他对 YouTube 的推荐算法忍无可忍，于是让 Claude 把 HN（Hacker News）20 年里 4300 万条评论过滤一遍，筛出被反复推荐的 6454 个视频，做成了自己的推荐站。

  • 全程只花了 ~2 小时（Claude Opus 5.5，Medium 档），人只做了三件「配套」活：在 Google Cloud 申请 API key、开一台 VPS、买域名。
  • 推荐质量「显著更好」，且无需登录（状态存在本地浏览器会话里）。
  • 缩略图取视频中段的代表性帧，而不是把上传者 A/B 测试调优到极致的诱哄封面。
  • 底层的评论分析数据打包成一个 zip，你可以让 Claude 拿它生成自己的版本。还有个「HackerTube Longs ✊」。

他自己的总结是点睛之笔：「很多以前要花几周甚至几个月的项目，现在早上起来少吃个早饭的功夫就能做出来。我们还有什么没想到的？」这条帖子 3.6 万点赞、3000+ 转发，是今天绝对的「头条」。这也是 Claude Code（Mac 桌面版）+ Opus 5.5 作为默认开发工具的一次顶流示范。

二、模型与开源：本地模型的回潮

Vercel CEO Guillermo Rauch 抛出今天的「金句」，转发 222 次：

Own your intelligence.（拥有你自己的智能。）

任何反对这一点的人，都有东西要卖给你——也许是你自己的智能，卖回给你。

本地模型需要继续扩散。那些「巨无霸」级的大模型在本地暂时还跑不动，所以你最好的选择确实是：保持选择开放。拥有你自己的 harness、数据、连接、运行时——你自己的 agent。拥抱开源。

同一天两条落地信号呼应了他的话：

  • Garry Tan 转发 Particle-1：一个「和更大的模型在 agentic 检索上同样能打，但价格只有 1/23」的新模型——这正是本地/小模型实用主义的典型样本。
  • Rauch 本人在重度测试 Gemini：在两个高复杂度项目上表现「非常好」，他甚至半开玩笑说「SUPER EXCITED」。

三、产品与 Agent 开发：Claude Code 驱动的潮流

除了 Karpathy，Claude Code 生态今天也相当活跃：

  • Thariq（前 Anthropic Claude Code 团队成员）在做一款 WoW 题材游戏，新加了一个「玩火的跆拳道大师」角色，并把美术从 3D 模型改成了生成式 sprite。他预计下周能出一个 vertical slice。这是「一人 + Claude Code 做游戏」的又一样本（990 赞）。
  • Amjad Masad（Replit CEO）展示 Replit 的一个一键开关：在网站上开启「反馈小组件」后，用户的反馈会直接变成 agent 的 prompt 去继续构建——把「用户说的话」自动流转成「agent 的活」，这是产品自驱开发的一个清晰方向。

四、行业观点与风向

  • Amjad Masad 的警告（2266 赞）：「如果你正在享受补贴型的 AI 订阅，准备被 rug pull 吧。」——暗指当前各家 AI 订阅在烧钱获客，补贴一旦退场，价格/能力会骤变。给「依赖单一订阅」的个人和团队敲警钟。
  • Aaron Levie（Box CEO）给出今天最有「结构性」的观察：我们正从「agent 帮我们更快更好地干活」的世界，转向「我们帮 agent 干活」的世界。于是，很多岗位（不仅限于编程）的新工作描述会变成「一支 agent 团队的管理者」，而非「带着一点 AI 杠杆的个人贡献者」。影响最大的将是信息密集型岗位：编程、安全、法律、生物科技、工程。逻辑链条很硬——知识工作历史上的唯一杠杆是「投入的工时」，而 agent 第一次把「工时」和「产出」这两个变量解耦了。
  • Garry Tan：「Practical robotics is nigh」（实用机器人不远了），转发的是一条机器人演示。机器人 + hard tech 是 YC 持续加注的方向。
  • Peter Yang用一张清单回答了「能不能只用一个 AI 工具」：目前每个品类都有明确赢家——浏览器/电脑操作 = ChatGPT + Codex；设计/视频剪辑/「品味」= Claude；24/7 agent 和定时任务 = Grok Bot。Gemini 在写作上被低估但还需更多测试。

五、Codex 挑战进行时

OpenAI 的 Thibault Sottiaux 继续他的 Codex 每日挑战，更新到 Day 28 / Banked 2/2（7495 赞）。这条本身信息量不大，但它代表一个持续进行中的公共实验——每天用 Codex 完成真实任务并公开进程，是当前量化 agent 编程能力上限的重要参照。

小结

今天的共识很清晰：模型能力的军备竞赛仍在，但增量价值正从「使用权」转向「所有权」。Karpathy 用一场 2 小时的 hack 证明「工具+时间」的复利，Rauch 和 Masad 从不同角度提醒「别把智能抵押给补贴」。对读者来说，能带走的一句话是：守住你自己的数据、harness 与运行时，保持多模型多工具的可迁移性——这是下一个周期里唯一不会贬值的资产。
