今日主线

一天之内，多个信号指向同一件事：Agent 正在从「演示玩具」变成「真正把手伸进你的文件、代码和基础设施里干活」的执行者。Gemini 4 Carbon 上线、Claude 交互式工作区铺开、Box 对 Claude 开放文件读写、Vercel 的 Agent 一周修掉 1.4 万个漏洞——模型不再只是「聊得更聪明」，而是开始直接产出。

Agent 正在从辅助变成执行者：从「替我写」进化到「替我干」——而安全、评测与协作文化，正在成为这轮跃迁的胜负手。

小结

今天的图景很一致：模型能力已够，接下来的竞争在「把手伸进现实世界」的执行层。Claude 用 interactive connectors 把第三方工具拉进对话、Box 用 MCP 把企业文件交出去、Vercel 让 Agent 直接修漏洞——都在把 Agent 从「聊」推向「干」。而 Thariq 与 Ryo Lu 的提醒同样关键：别只做一次性 demo，真正的魔法在人与人的协作，而非孤岛里的 Agent 军团。
