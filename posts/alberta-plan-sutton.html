Sutton 的逆潮流赌注：Alberta Plan——12步从不停止学习的 AI 路线图

July 30, 2026

Sutton 的逆潮流赌注：一个没有训练集、没有人类标注、每个时刻都在学习的 AI 路线图

2023年，强化学习之父 Richard Sutton 在 arXiv 上发布了一份特殊的研究计划——不是一篇实证论文，而是一份长达 12 步的 AI 研究路线图。Alberta Plan 的核心赌注是：真正通用的智能必须在一个持续变化的世界中，从零开始、每个时刻都在学习，不需要特制训练集，不需要人类辅助，只需要三个信号：观察、动作、奖励。

这份计划之所以重要，不是因为它在当时取得了什么benchmark成绩——它没有。而是因为它提供了一套原则驱动的、与主流 AI 大模型路径完全正交的研究范式。在所有人都在堆数据、堆算力、堆人类标注的时候，Sutton 说：这条路走不远。

核心原则：时间均匀性——所有时刻平等

Alberta Plan 最激进的原则是 Temporal Uniformity（时间均匀性）：agent 在每一个时间步同时进行学习、规划和元学习。没有"训练阶段"，没有"测试阶段"，没有 episode reset。一切都在持续进行。

这意味着：

  • 学习不是一件"训练完就停止"的事——它是 agent 存在的定义
  • 规划不是在"需要做决策时"才启动——它在后台持续异步运行
  • 元学习（学习怎么学习）也不是一个独立的阶段——它和基础学习在每个时间步同时发生

这与当前 LLM agent 的范式形成鲜明对比：LLM 先在人类数据上预训练（特殊的"训练期"），然后通过 RLHF/DPO 对齐（另一个"特殊期"），最后在部署时推理（"测试期"）。Alberta Plan 会说：这三个阶段应该在每个时间步统一进行。

Base Agent：四个组件，持续运转

Sutton 的 base agent 基于他 2022 年提出的 "Common Model of the Intelligent Agent"——一个横跨 AI、心理学、控制论、神经科学和经济学的共同智能模型。

组件功能运行模式
Perception将观察信号压缩为状态表示前台，每步必执行
Reactive Policies选择动作发送到环境前台，每步必执行
Value Functions评估状态和动作的价值前台学习 + 规划使用
Transition Model学习世界动力学，预测状态转移后台异步规划

关键设计选择：模型学习在状态空间进行，不涉及观察空间。这意味着 agent 在内部构建的"世界模型"是对其自身状态压缩的预测，而非原始感官信号的重建。这是一个重要的抽象边界。

最被 Sutton 承认的薄弱环节是 Perception——"关于感知应该如何学习以最大程度支持其他组件，仍然是一个开放问题。"

STOMP → Oak：从扁平 RL 到自我改进的层次化认知

Alberta Plan 最吸引人的技术贡献是两个递进的架构：STOMP Progression（步骤10）和 Oak Architecture（步骤11）。

STOMP = SubTask → Option → Model → Planning。这是一个从扁平 RL 构建时间抽象认知结构的递进机制：

阶段做什么产出
SubTask选中的高排名状态特征定义子任务（最大化该特征的终止值）子任务定义
Option为子任务学习策略 + 终止条件（需 off-policy 学习）可执行的选项
Model学习该选项的 transition model可预测的状态转移模型
Planning将选项模型加入异步规划过程更好的策略

Oak 在 STOMP 基础上加入反馈循环：持续评估每个元素（特征 → 子任务 → 选项 → 模型）的效用。计划中从未被使用的选项模型？删除。不再有用的子任务？替换为基于新特征的。Oak 不是静态架构，而是一个持续自我优化的系统。

Oak 还引入了 Option Keyboard 概念——通过实值向量引用和组合选项。单个分量是一个子任务，多个非零分量构成"和弦"，连续地组合多个选项。这在数学上把离散的工具选择变成了可微的组合空间。

12步路线图：从步长元学习到智能增强

整个 Alberta Plan 的逻辑是"front load"——在每个问题上先用最简单场景解决核心挑战，再逐步泛化：

步骤核心任务对应能力
1-2持续监督学习 + 特征发现Representation
3-4GVF 预测 + Actor-Critic 控制Prediction & Control
5-6平均奖励 GVF + 持续控制问题Continuing Settings
7-9平均奖励规划 + 一步模型 RL + 搜索控制Planning
10-11STOMP + Oak（时间抽象 + 自我改进）Prototype AI
12智能增强（计算性外脑）IA

步骤12的终极目标是 Intelligence Amplification（智能增强）：构建一个"计算性外脑"——先是 exo-cerebellum（增强感知和预测），后是 exo-cortex（增强策略和规划），乘法级地放大另一个 agent 的智能。

Bitter Lesson 的物理化

Alberta Plan 本质上是 Sutton 2019 年 "The Bitter Lesson" 的工程实例化。Bitter Lesson 的核心洞见：AI 研究 70 年最大的教训是，利用算力的通用方法（搜索、学习）总是最终胜出——且领先幅度巨大。任何试图将人类领域知识编码进 AI 系统的努力，都是短视的。

方法类别可随算力扩展长期胜出例子
搜索✅✅Deep Blue, AlphaGo
学习✅✅深度学习, RL
人类知识工程❌❌专家系统
人类标注数据部分❌监督学习瓶颈

Alberta Plan 将这条原则推到了极致：不仅不要人类知识，连训练集都不要。Agent 从零开始，只通过与环境的持续交互来学习一切——包括学什么、怎么学、什么时候忘掉旧的、什么时候创造新的。

对 Agent 工程的三点启示

1. 元学习不是附加功能，是核心架构

Alberta Plan 的第一步就是研究自动调整学习率（步长）的元算法。在当前 LLM agent 中，这对应的是自动调整 prompt、自动选择工具、自动评估输出的"meta-agent loop"。但目前大多数 agent 系统把这些作为外挂（如 reflection loops），而非内建于架构。Oak 式的持续效用评估——每个组件都在被评估、排名、可能被替换——是 agent self-improvement 的终极形态。

2. 时间抽象是 scaling 的关键

STOMP 递进的关键洞察：子任务发现 → 选项学习 → 模型构建 → 规划使用，四个阶段在一个反馈循环中持续运转。当前 agent 的 tool use 类似于"选择一个选项执行"，但缺乏 Oak 式的自动发现、评估和撤回选项的能力。一个真正 scale 的 agent 系统需要能自己发现、优化和废弃技能。

3. Agent 不应有"训练"和"部署"的界限

这是 Alberta Plan 对当前 LLM agent 范式最根本的挑战。LLM 的训练（预训练 + 对齐）和部署（推理）是完全分离的阶段。Alberta Plan 的时间均匀性意味着：每一次 agent 与环境的交互，都应该同时是执行、学习和改进。这对应的是真正的 continual fine-tuning agent——目前几乎没有生产系统能做到这一点。

局限与诚实标注

  • Perception 未解决（论文自认）：Sutton 明确承认 Perception 是四个组件中"最不被理解的"。如何将原始观察学习压缩为有用状态是一个开放问题——这恰恰是 LLM 擅长的领域。
  • 从零开始的高昂代价（我的推断）：Alberta Plan 假设 agent 从 tabula rasa 开始学习一切。这在实际时间尺度上可能不现实——预训练知识（如 LLM）的迁移优势被完全放弃了。
  • 安全与对齐未涉及（我的推断）：论文简单断言"更有远见的智能总体上对世界有益"，在 2026 年看来过于乐观。无约束的持续自我改进系统带来了显著的安全风险。
  • 实验验证缺失：到 2024 年初，12 步中只有前几步有实质性算法进展（如 step-size adaptation 的 Auto 算法）。STOMP 和 Oak 仍是概念性架构。
  • 非平稳性假设：算法假设环境变化缓慢且平滑，现实世界可能不满足。

一句话

Alberta Plan 是为 AI 研究划定的一条逆潮流路线：放弃训练集、放弃人类标注、放弃阶段划分，赌注是——真正的智能只能在永不停止的学习中涌现。
