一、Claude Code 官宣支持 AGENTS.md：harness 标准化的信号

Anthropic 的 Thariq 宣布 Claude Code 从 v2.1.277 起支持 AGENTS.md：目录下没有 CLAUDE.md 时，Claude 会自动读取并使用 AGENTS.md，行为可在设置中切换（原文，25.5k 赞 / 2.1k 转）。这是编辑器大战以来 agent 工具链最重要的互操作性动作之一——项目指令文件终于有望跨工具通用。他随后补充了实现细节：AGENTS.md 支持基于 Claude Code 即将推出的「mods」机制构建，这是他们自定义 harness 的新方式，内置 mod 之外开发者也能写自定义版本（原文，926 赞），并开放了 mod 的源码（原文）。OpenAI 侧，Codex 团队的 Thibault Sottiaux 预告正在和 Sam Altman 一起准备 keynote，「好东西多到不知道怎么讲完」（原文，3.6k 赞）——两边在同一天有动作，harness 层的竞争正在升温。

二、Jev 全面爆火：开源模型的采用曲线很陡

Vercel CEO Guillermo Rauch 给出数据：当天 Vercel AI Gateway 的 token 流量中开源模型占 78.4%、闭源仅 21.6%，用量前四里第三、四位是 Moonshot 的开源模型（原文）。而他关于 Jev 的观察更值得细读：采用数据「令人震惊，所有人都在采用」——他认为这不只是产品好，更是「AI 太贵太慢」这种行业情绪的下游结果：用户在为低成本找出口（原文，711 赞）。生态反应速度极快：Nikunj Kothari 用 Jev 在 28 秒内按多重标准给 3000 种儿童零食打分，成本 $0.11（原文，486 赞），还顺手做了个聚合站 Jevable 收录全网 demo（原文）；Rauch 自己也在周末前排队尝鲜「Free Jev」（原文，1.8k 赞）。企业侧同样快速跟进，Box CEO Aaron Levie 演示了 Jev 在企业工作流里做秒级判断和数据分类的用法（原文，500 赞）。

三、个人 agent 接活：Meta Muse 替人砍价省下 $800/年

Peter Yang 的实测值得关注：Meta 的 Muse 是他至今用过最好的个人 agent，帮他跟运营商谈下了每年 $800+ 的账单减免，而产品本身免费（原文，707 赞）。更有意思的是那份电话谈判记录——Muse 和 Comcast 客服来回拉锯替他省了 $288/年，他的判断是大多数公司的客服热线还没准备好面对 AI 谈判者（原文，230 赞）。这是「agent 有真实经济价值」最直白的一个样本：不写代码、不做分析，就是打电话省钱。

Claude 官方博客宣布 Cowork 与聊天合并为同一个 Claude：随口提问和「中午要交的报告」走同一个入口，合上笔记本后任务继续跑，未来几周内推送到 Pro/Max（原文）。同日发布 Claude Docs 与 Claude Slides，Claude Design 也进入对话流——要文档就一起写，要演示就一起出 slide，可直接编辑、可从 Claude 内直接演示、也可导出 PowerPoint/PDF。官方解释合并的动机：用户最烦的就是「这个任务该放哪儿」，以及在一边开了头另一边接不上。agent 产品在做减法，这和昨天讨论的 harness 整合是同一个方向。
