AI Builders 日报 · 2026-11-14

November 14, 2026

今天的 feed 有两条主线：一条是昨天开始发酵的 Jensen Huang 风波，今天升级为一场科技领袖的集体签名行动——「Stand with Jensen」公开信在 builder 圈刷屏；另一条是 agent 本身在加速商业化与工程化，Vercel 交出了可复用的耐久层 durable-harness，Replit 联手 Visa 试水 agentic commerce。震荡没有停，但建设也在继续。

当舆论把一位掌舵人推到风口，同行们用签名站队；与此同时，agent 基建正在悄悄长出「可复用的可靠性层」——真正的进展，永远发生在喧嚣之外。

一、Stand with Jensen：从舆论到集体签名

昨天的讨论今天直接升级成了行动。多位 builder 公开签名并呼吁联署「Stand with Jensen」公开信：

  • Guillermo Rauch（Vercel CEO，3392 赞）一句话「Co-sign」（联署），转发量极高；同一天他还连发两条 agent 基建相关推文（见下节），态度鲜明。
  • Amjad Masad（Replit CEO，2557 赞 / 367 转）：「读一读 Stand with Jensen 公开信，考虑加上你的名字」。
  • Garry Tan（YC CEO，2017 赞 / 122 转）：「Jensen 应得到正当程序（due process），而不是现在正在发生的一切。我签了。」
  • Amjad Masad 还透露了一个细节：StandWithJensen 这个页面本身就用 Replit 搭建并托管，昨天访问暴增触发了限流，Replit 团队已协助页面所有者把限流抬上去，「现在应该能扛住了」（1270 赞 / 104 转）——一桩技术小事，反而成了这波签名运动的注脚。
  • Peter Yang（16 赞）则提供了另一侧声音，指向报道本身的可疑之处：所谓「Alice Huang 是间谍」的说法，即便 WSJ 已下结论，目前仍不明确；他贴出新加坡政府官网的公开资料作为佐证，并呼吁「看这条的人自己做研究」。

一句话：签名从个体表态走向集体行动，而「报道是否站得住脚」的质疑也同步浮出水面。真相未明之前，两边都应该被记录。

二、Agent 基建：Vercel 的可复用耐久层 durable-harness

Guillermo Rauch（345 赞）正式总结 Workflow SDK 5 与 Vercel Workflows 的四大进展：

  • 「首步耗时」与「步间耗时」大幅下降；
  • 加密与安全性翻倍投入；
  • 系统可靠性已在超大流量下得到验证，并实战演练过多种灾难恢复场景；
  • 最关键的一点：底层的耐久日志（durability log）被做成了可复用的组件，任何 agent harness 都能用——它有了独立的名字 durable-harness。

「Underlying durability log, reusable for any agent harness」——这句话的分量在于：agent 的「状态存续」问题，正在从每家自造轮子，走向标准化、可复用的基础设施。同日他还抛出一句短评「Vercel Sandbox is inevitable」（227 赞），继续押注沙箱化执行环境。

三、Agent 商业化：Replit × Visa 的 agentic commerce

Amjad Masad（105 赞）宣布与 Visa 在「agentic commerce」（agent 商务）上的合作进展：「能与 Visa 合作非常棒，更多功能和用例即将到来。」

这是一个方向性信号：agent 开始触碰真实的支付与交易闭环。当 agent 不仅能生成内容、写代码，还能代理用户完成下单、支付，「谁来为 agent 的行为负责」就不再是假设题，而是工程题和合规题。

四、评测：Opus 5.5 仍是编码默认，Fable 5.2 胜在「差不多但更贵」

Garry Tan（154 赞）放出了一组一手评测数据，结论很务实：

在 Claude Code 2.1.322 的 52 个编码任务上，Fable 5.2 解决率与 Opus 5.5 大致相当（82.7% vs 84.6%），但每个已解决任务的平均成本却是 Opus 的 2.80 倍——所以，编码默认继续用 Opus 5.5。

他还开源了自己的 harness 评测仓库并分享了发现（135 赞），主张用「真正难的任务」来区分头部模型，因为「Opus 已经能解决大部分这些任务」。这与昨天 Nikunj 的「benchmark-maxxing」吐槽形成呼应：与其追逐榜单，不如在自己真实工作流里用成本/解决率去衡量。

五、AI 医疗：一个免费 skill，帮患者打「难缠的病」

Peter Yang（434 赞 / 36 转）发布了他最「接地气」的一条：一个免费 skill——/fuck-cancer。流程三步：

  1. 把患者所有病历上传到一个文件夹（如 Google Drive）；
  2. 让 ChatGPT 或 Claude 安装这个免费 skill（指向链接即可）；
  3. 把 skill 指向病历文件夹，它会生成一页纸摘要、检索临床试验等。

他也欢迎把它 fork 并改造用于其它长期疾病。让 AI 的「全功率」落在最具体、最痛的地方，这条在 feed 里点赞数仅次于几个签名表态，可见共鸣。

六、行业动态：FAA 停飞与 AI 100 名单

  • FAA 全国地面停飞：Nikunj Kothari（54 赞）点出一个惊人事实——这是现代史上第三次全国机场地面停飞：第一次是 9/11，第二次是 2023 年的 NOTAM 系统宕机，第三次就是今天（原因还不明）。Matt Turck（150 赞）半开玩笑地刷了一条「突发：VC 们即将就此发表意见」。虽是黑色幽默，一个「系统单点故障」的教训对 agent 基建同样成立——容灾与降级从来不是可选项。
  • AI 100 名单：Aditya Agarwal（SPC）为自家 portfolio 上榜的 AI 100 公司庆贺（29 赞）：Baseten、Render、Profound、Replit、Gamma、Cog、Density——这批正在定义的「AI 原生工具栈」值得盯紧。

七、播客：Continual Learning，从「伪持续学习」到真正的闭环

本期 Training Data 邀请 Trajectory 的 Ronak 聊「Continual Learning」。核心比喻是用人类大脑做参照：我们是真正的持续学习者——在线学习、不断更新迭代；而当下 agent/AI 的世界，用他的话说还处在「pseudo continual learning（伪持续学习）」状态。Trajectory 的产品哲学是「把训练、评测、部署放进同一个地方，让每个人都觉得简单，然后闭环：把模型推回生产、收集新 trace」——这套「训练-部署-回流」的一体化，是他认为每家公司在不远的将来都会采纳的范式。

八、小结

  • 舆论与建设并行：一边是 Stand with Jensen 签名运动把 NVIDIA 风波推向政治化，一边是 Vercel、Replit 把 agent 的「可靠性」与「交易闭环」往前推了一步。
  • 一个反复出现的工程信号：agent 的耐久层（durable-harness）正在标准化，「可复用的可靠性」成为新战场，而不是每家自己造轮子。
  • 评测回归理性：Garry Tan 的「82.7% vs 84.6%、价差 2.80×」提醒我们，真实工作流里的成本效率，比榜单名次更有决策价值。
